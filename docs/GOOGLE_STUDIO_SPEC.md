# 耳语·回声 - Google Studio 产品设计规格说明

> 供 AI 生成界面与功能实现的设计文档

---

## 1. 产品概述

**产品名称**：耳语·回声（Whisper & Echo）

**核心定位**：让播客从「被动收听」变为「主动思考」的个人知识管理工具

**目标用户**：有深度学习需求的播客听众

**核心 Slogan**：让声音留下痕迹

**技术栈**：React + Vite 前端，Node.js 后端，本地存储（不涉及云端与账号系统）

---

## 2. 设计风格与视觉规范

### 2.1 配色
| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | #FAF7F2 | 暖白 |
| 卡片 | #F0EBE0 | 浅原木色 |
| 主文字 | #4A4A4A / #1a1a1a | 深灰 / 墨水黑 |
| 次要文字 | #8B8B8B | 副文案 |
| 强调色 1 | #A7B89E | 鼠尾草绿 |
| 强调色 2 | #D4C5B5 | 陶土色 |

### 2.2 字体
- **标题**：Playfair Display（衬线）
- **正文**：Inter（无衬线）
- **辅助信息**：等宽字体（font-mono）用于时间、标签等

### 2.3 气质
安静、温暖、不催促。整体像一个专属的思考空间。

**布局示意：**
```
┌─────────────────────────────────────────────────┐
│ Whisper·Echo              今日会话              │
│                          2月18日 星期三          │
├─────────────────────────────────────────────────┤
│                                                 │
│ ┌──────────────────┐  ┌──────────────────┐     │
│ │  [耳机图标]       │  │  [书本图标]       │     │
│ │  我的播客         │  │  笔记仓库         │     │
│ │  存放你导入的...  │  │  你留下的思考...  │     │
│ │  已导入 [1]      │  │  笔记数 [2]       │     │
│ └──────────────────┘  └──────────────────┘     │
│                                                 │

```

**元素说明：**
- 左上：品牌名 Whisper·Echo（两行，衬线体）
- 右上：今日会话 + 日期（格式：X月X日星期X）
- 两卡片左右排列：
  - 左卡片：浅色背景，耳机图标，标题「我的播客」，描述「存放你导入的声音，开始新的听想旅程。」，底部「已导入」+ 数字徽章

**交互：**
- 点击左卡片 → 进入播客列表页
- 点击右卡片 → 进入笔记仓库页

### 3.3 页面三：播放页（核心页）

**布局示意：**
```
┌─────────────────────────────────────────────────┐
│ ← 返回    NOW PLAYING                           │
├─────────────────────┬───────────────────────────┤
│ [封面图]            │ 我的笔记 | AI 对话        │
│ 节目标题            ├───────────────────────────┤
│ 节目名/创作者       │                           │
│                     │ ① 笔记内容...  [编辑][删] │
│ 3:46 ━━━━━●━━━ 75:29│                           │
│      [▶ 播放]       │ ② 笔记内容...  [编辑][删] │
│                     │                           │
│ 概览 | 全文         │ [输入框] 记录想法... [发送]│
│                     │                           │
│ - 01:44 前AI时代... │                           │
│ - 03:52 简历分成... │                           │
└─────────────────────┴───────────────────────────┘
```

**左半区（播放与文稿）：**
- 返回按钮 + 标题 NOW PLAYING
- 封面、节目标题、创作者
- 进度条（当前时间 / 总时长，可点击拖动）
- 播放/暂停按钮
- Tab：「概览」「全文」
  - 概览：重点节点列表（时间戳 + 标题）
  - 全文：逐字稿或 RSS 简介

**右半区（笔记与对话）：**
- Tab：「我的笔记」「AI 对话」
- 我的笔记：列表按时间正序，每条有 ①②③④ 编号、编辑、删除
- 底部输入框：直接输入想法 + 发送
- AI 对话：对话气泡 + 底部输入框

**布局要求：**
- 左右 50% 平分，**无中间可拖动分割线**
- AI 对话与我的笔记在右半区切换，布局一致

**交互：**
- 划选逐字稿 → 弹出「记笔记」浮层，点击后原文带入笔记框
- 点击时间戳 → 跳转播放位置
- 删除笔记 → 弹出确认框「确定删除这条笔记吗？」

## 4. 功能规格

### 4.1 RSS 导入
- 输入 RSS 链接 → 获取节目列表
- 支持搜索节目名称
- 点击单期导入，写入本地存储
- 音频 URL 从 enclosure 提取

### 4.2 播放器
- 播放/暂停、进度条（可拖动）
- 通过后端 `/audio-proxy?url=...` 代理音频，规避 CORS
- 退出时保存进度，再次进入从上次位置恢复

### 4.3 逐字稿
- 展示逐字稿或 RSS 简介
- 支持划词，弹出「记笔记」
- 点击时间戳跳转播放位置（如有）

### 4.4 笔记
- 划词笔记：原文自动带入
- 直接输入：右侧输入框
- 按时间正序显示
- 编辑、删除（删除需确认）

### 4.5 AI 对话
- 独立 Tab，基于全文问答
- 接入 API（如 DeepSeek/Gemini）
- 对话记录不持久化

### 4.6 笔记仓库
- 按节目聚合
- 显示笔记数量
- 点击进入只读笔记详情

---

## 5. 边界情况

| 场景 | 处理方式 |
|------|----------|
| RSS 链接无效 | 提示「无法解析该 RSS 链接，请确认链接是否正确且为有效的播客 feed」 |
| 重复导入节目 | 提示「该播客已经存在」，阻止重复导入 |
| 删除笔记 | 确认框「确定删除这条笔记吗？」 |

---

## 6. 技术约定

- **存储**：浏览器 localStorage
- **代理**：前端请求 `/api/*` 由 Vite 代理至后端；音频通过 `/api/audio-proxy?url=...` 代理
- **后端端口**：8787
- **前端端口**：3001
